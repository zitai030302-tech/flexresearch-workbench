# Contributing

Thank you for improving FlexResearch Copilot.

## Before opening a pull request

1. Keep changes local-first and evidence-first.
2. Do not add unpublished papers, proprietary SOPs, identifiable health data, instrument credentials, API keys, or laboratory raw data to the repository.
3. Add or update tests for behavior changes.
4. Run `python -m compileall -q app.py tests` and `python -m pytest -q`.

## Research-content boundary

Public evidence cards must link to a stable public source. Experimental recommendations must be framed as reviewable drafts, not validated scientific or clinical conclusions. New measurement calculations should document assumptions, input units, and limitations.
