MVP workspace

把研究任务拆成三个可执行模块

所有结果均保留来源或计算过程。此版本不使用语言模型生成“无证据结论”。

01 / 文献证据

Literature Copilot

从公开来源中定位方向、成果与可追溯链接。

02 / 实验草案

Experiment Planner

按研究方向生成可供导师和同门审阅的计划框架。

03 / 数据分析

Data Analyzer

识别 I–V、应变—电阻、循环稳定性、光谱响应与通用信号，并把计算结果回写至本地测试台账。
